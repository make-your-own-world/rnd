# Density-Balanced QEM

Density-Balanced QEM documents MeshMill's density-aware adaptation of established QEM and robust-statistics techniques for nonuniform scanned and composite geometry.

- [Read the paper](paper.md)
- [Download the rendered paper](density-balanced-qem-v1.0.pdf)
- [Citation metadata](CITATION.cff)
- [Research attribution](RESEARCH_ATTRIBUTION.md)
- [Normalized quality results](data/quality-results.csv)

The publication records density as useful reduction evidence, while documenting why density alone is not a complete surface model. It is followed chronologically by Depth Adaptive QEM and Depth + Density Adaptive QEM.

The source fixture and generated meshes are not distributed. Reported values describe the retained benchmark fixture and target counts.
