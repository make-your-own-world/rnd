# Boundary-Preserved Deterministic QEM

Boundary-Preserved Deterministic QEM documents MeshMill's bounded-memory tiled path for large binary STL meshes: deterministic target allocation, protected tile boundaries, memory-bounded worker scheduling, validated checkpoints, cancellation-safe streamed assembly, and byte-identical tested output.

The report distinguishes established out-of-core and QEM foundations from the tested integration, recovery, determinism, and assembly contracts evaluated here.

The source fixture and generated meshes are not distributed. Reported values describe the retained benchmark fixture and target counts.
