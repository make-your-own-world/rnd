# Depth + Density Adaptive QEM

Depth + Density Adaptive QEM combines adaptive depth-gauge surface evidence with robust local density weighting, then applies a boundary-aware global QEM pass for topology reduction.

The publication distinguishes measured production behavior from explanatory models and records the runtime cost of the earlier attribute-QEM hybrid. Its figures compare Fast QEM, Density-Balanced QEM, Depth Adaptive QEM, and the combined method on the retained fixture.

The source fixture and generated meshes are not distributed. Reported values describe the retained benchmark fixture and target counts.
